# SKIFF RUN 0.1.0

Palm-era trade loop homage. Original systems, goods, and ships. **Not** official Space Trader. **Not** a Paramount product.

Sibling to [Hex Wake (repo: space-war)](https://github.com/ofonedev-dot/space-war) — related night palette, different rules.

Open `index.html` locally or enable GitHub Pages on `main` / root.

## How to play

1. Buy low / sell high across systems.
2. Travel burns fuel — refuel at stations.
3. Encounters: **Ledger Wardens** (fines) or **Ash Corsairs** (theft / fight flee).
4. Reach **₩120,000** net worth and retire on **Quiet Moon**.

Save is automatic (`localStorage`).

## Pages

Settings → Pages → Deploy from branch `main` / `/ (root)`.
Expected URL pattern: `https://<user>.github.io/skiff-run/`
